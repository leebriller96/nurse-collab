# 테스트 시나리오 — 손으로 따라 하며 확인하는 전체 케이스

작성: 2026-09-17 (KST)
대상: 로컬에서 띄운 한 서버 구성(화면 `http://localhost:5173`, 백엔드 `http://localhost:8080`)
선행 문서: `02-api-spec.md`(오류 코드), `04-screens-permissions.md`(화면·권한), `06-hospital-scale.md`(원내/업무 분리)

각 케이스는 **사전 조건 → 단계 → 기대 결과** 로 적는다. 버튼·문구는 화면에 실제로 적힌 그대로다.
마지막 칸 **자동** 은 같은 것을 확인하는 자동 검사다. 비어 있으면 손으로만 확인할 수 있는 케이스다.
자동 검사가 있는 케이스도 한 번은 눈으로 본다 — 자동 검사는 "깨지지 않았다" 를 지키고,
사람은 "쓸 만하다" 를 본다.

## 0. 준비

### 0-1. 서버와 데이터

```bash
docker compose up -d                                   # postgres, redis
./gradlew bootRun                                      # 백엔드 :8080
cd frontend && npm run dev                             # 화면 :5173
PG_VIA_DOCKER=nurse-collab-postgres SEED_DIR=ops/demo-reset/seed node ops/demo-reset/reset.mjs
```

**케이스 묶음을 시작할 때마다 초기화를 다시 돌린다.** 앞 케이스가 요청 상태를 바꿔 놓으면
뒤 케이스의 사전 조건이 맞지 않는다.

### 0-4. 표기

- **두 창** 이 필요한 케이스는 일반 창과 시크릿 창을 쓴다. 로그인 정보가 창마다 따로 남는다.
- **원내 끊기** 는 Chrome 개발자 도구 → Network → 요청을 오른쪽 클릭 → *Block request URL pattern* 에
  `*/api/v1/phi/*` 를 넣는다. 원내 서버에 닿지 못하는 상황과 같다(응답이 오지 않는다).
- **오프라인** 은 개발자 도구 → Network → *Offline*.
- **폰 화면** 은 개발자 도구 → 기기 모드 → 375px 폭.

## 8. 원내 분리 배포 (선택 — Docker)

한 서버 구성이 아니라 업무 서버와 원내 서버를 따로 띄운다. 이미지 빌드에 몇 분 걸린다.

```bash
export POSTGRES_PASSWORD=local PHI_POSTGRES_PASSWORD=local-phi JWT_KEYS_DIR=./keys WEB_PORT=8082 WEB_TLS_PORT=8444
mkdir -p keys && openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out keys/jwt-private.pem \
  && openssl rsa -in keys/jwt-private.pem -pubout -out keys/jwt-public.pem
docker compose -p split -f docker-compose.split.yml up -d --build
```

| ID | 단계 | 기대 결과 | 자동 |
|---|---|---|---|
| S-01 | `docker compose -p split -f docker-compose.split.yml ps` | 7개 모두 Up (postgres, redis, phi-postgres, backend, onprem, web, demo-reset) | CI |
| S-02 | `... exec backend getent hosts phi-postgres` | 아무것도 나오지 않는다 — 업무 서버는 원내 DB 에 닿지 않는다 | CI 원내 격리 확인 |
| S-03 | `... exec onprem ls /run/keys` | `jwt-public.pem` 하나뿐 | CI 원내 격리 확인 |
| S-04 | `http://localhost:8082` 에서 1~7장 케이스 일부 | 한 서버 구성과 같게 동작한다 | CI 브라우저 검사 |
